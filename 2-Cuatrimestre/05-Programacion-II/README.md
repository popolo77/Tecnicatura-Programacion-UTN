## 📝 Presentación de la Materia

Esta asignatura representa el salto fundamental hacia el desarrollo de software profesional e industrial. En **Programación II** profundizamos la lógica algorítmica evolucionando hacia el **Paradigma Orientado a Objetos (POO)**.

Utilizamos **Java** como lenguaje principal, trabajando sobre el entorno **Apache NetBeans** e integrando conceptos clave como estructuras de datos dinámicas, diagramado UML, gestión de excepciones, uso de genéricos y persistencia en bases de datos relacionales mediante **JDBC**.
